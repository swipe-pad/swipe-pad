# Official Docs

Primary sources for Neynar work related to Mini Apps:

- App host overview: https://docs.neynar.com/docs/app-host-overview
- Docs root: https://docs.neynar.com/

Usage in SwipePad:

- Neynar is not required for baseline Mini App bootstrap.
- Reserve Neynar for server-side auth, webhooks, or richer Farcaster API workflows.
- Treat `NEYNAR_API_KEY` as optional until a concrete server feature needs it.
