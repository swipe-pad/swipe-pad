Stage and commit the current changes following the project's commit format rules.

1. Run `git status` and `git diff --stat` to see changes
2. Group changes into logical chunks by component/purpose
3. Stage each chunk separately: `git add <files>`
4. Format each commit: ``<emoji> <type>(<scope>): <subject>``
5. Use imperative mood, lowercase, max 50 chars, no trailing period
6. Repeat until clean

Never commit without user confirmation first.
